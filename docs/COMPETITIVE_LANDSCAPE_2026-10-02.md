# Competitive Landscape — IFRS-AI Inspector

**Date:** 2026-10-02  
**Scope:** standards-aware financial-reporting and assurance digital-twin research.

## Representative competitors

1. **MindBridge AI** — transaction/revenue risk analytics.
2. **Optro (formerly AuditBoard)** — controls, compliance, audit and GRC workflow.

## Capability matrix

| Dimension | IFRS-AI Inspector target | MindBridge | Optro |
|---|---|---|---|
| Transaction / revenue anomaly detection | Input signal to judgment layer | Strong public capability incl. revenue analytics | Possible via analytics/control workflows |
| IFRS paragraph-level judgment | Core target | Not evident as core public positioning | Not evident as core public positioning |
| Accounting treatment alternatives | Core target | Not central | Not central |
| Evidence-to-standard traceability | Core differentiator hypothesis | Explainable risk/control points | Requirement/control/evidence mapping |
| Human approval for material judgment | Required | Professional judgment emphasized | Practitioner orchestration emphasized |
| Continuous standards monitoring | Target | Continuous financial oversight, not standards-first | Continuous GRC/compliance monitoring |

## Positioning hypothesis

Differentiate on **IFRS-native judgment + traceable evidence + explicit human approval**, while treating transaction analytics and GRC workflow as complementary inputs rather than capabilities to rebuild unnecessarily.

## Next competitive build

- Start with IFRS 15, IAS 36, IAS 37 and IFRS 9 judgment packs.
- Require paragraph-level source provenance and version dates.
- Add counter-argument and reviewer-agent tests before human approval.
- Benchmark against manually prepared accounting memos, not only LLM agreement.

## Evidence basis

This comparison uses publicly documented capabilities reviewed on 2026-10-02:

- MindBridge: full-population financial analysis, explainable risk scoring, anomaly detection, continuous/periodic monitoring, and audit/assurance workflows: https://www.mindbridge.ai/ and https://www.mindbridge.ai/technology/
- Optro (formerly AuditBoard): GRC, internal audit, controls/compliance, analytics, continuous monitoring, automated evidence and testing workflows: https://optro.ai/auditboard-to-optro and legacy product materials at https://auditboard.com/

**Boundary:** this is a capability-overlap map, not a claim of market superiority. "Not evident" means the capability was not evident in the reviewed public materials; it does not prove the competitor lacks it.
