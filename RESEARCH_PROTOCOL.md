# Scientific Discovery Protocol

IFRS-AI Inspector uses the NAAIL evidence-governed scientific workflow for research claims and substantive model upgrades.

## Canonical workflow

**Research Question → Literature Validation → Competing Hypotheses → Co-Scientist Critique/Ranking → ERA Empirical Design → Real Data + Code → AlphaEvolve / Computational Discovery → Latent-Structure Analysis → AI-to-AI Adversarial Review → Robustness/Falsification → Replication/OOS → Chain-of-Evidence → DAG Governance → Human Gate**

## Required principles

- Generate multiple competing hypotheses before confirmatory testing.
- Translate surviving hypotheses into reproducible empirical objects with data, variables, identification, code, metrics, and robustness tests.
- Compare models, prompts, constructs, estimators, and specifications under frozen fitness criteria; never optimize for p-values alone.
- Use latent-structure reasoning only when resulting structures can be interpreted and externally validated.
- Treat agent consensus as a proposal signal, not scientific truth.
- Retain failed tests, rejected hypotheses, and negative results in failure memory.
- Require literature validation, contradictory-evidence search, provenance, falsification, reproducibility, replication where feasible, and human approval before discovery claims.
